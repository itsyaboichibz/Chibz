# Chibuzo Daniel Okoli — Portfolio

## Preview
Open `index.html` in a browser. The opening film plays automatically, muted (required by most browsers). Use the SOUND OFF control to enable audio.

## Edit
- `index.html` — all page content and links
- `styles.css` — design, spacing, colors and responsive layouts
- `site.js` — menu and opening film sound control
- `assets/opening-film.mp4` — opening video; replace with another MP4 using the same filename
- `assets/opening-poster.jpg` — fallback image before video loads

## Publish
Upload the entire `chibuzo-portfolio` folder to your existing Netlify site's Deploys page. Keep the `assets`, `resume`, and `scripts` folders.

Note: Browser autoplay generally requires muted playback. The viewer can turn on sound using the control.
